# 🩺 Multi Disease Prediction System (Machine Learning)

## 📌 Project Overview

This project is a Machine Learning-based system that predicts multiple diseases using user input data.

The system can predict:

* Diabetes
* Heart Disease
* Parkinson’s Disease
* Kidney Disease

It uses trained ML models (Random Forest) to provide accurate predictions.

---

## 🚀 Features

* Multi-disease prediction in one system
* Uses real-world medical datasets
* Trained using Random Forest Classifier
* Command-line based user input system
* Modular and reusable code

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Joblib

---

## ⚙️ How It Works

1. User selects disease type
2. Inputs required medical parameters
3. Model predicts whether disease is present or not

---

## ▶️ How to Run

### Step 1: Install dependencies

```
pip install -r requirements.txt
```

### Step 2: Run the project

```
python app.py
```
